## About the Project

**ComplianceVerse AI** is an interactive, comprehensive educational suite built to demystify enterprise compliance frameworks, regulatory readiness, and internal security controls. The platform blends deterministic certification exam simulations with real-time AI guidance powered by Google Gemini, enabling practitioners to test, remediate, and master complex governance challenges.

### Core Focus Areas

- **SOC 2 Type II** — Trust Services Criteria: Security, Availability, Processing Integrity, Confidentiality, and Privacy.
- **ISO/IEC 27001:2022** — Information Security Management Systems (ISMS), Clauses 4–10, and Annex A Controls.
- **NIST CSF 2.0** — Govern, Identify, Protect, Detect, Respond, and Recover functions.
- **HIPAA Security & Privacy Rules** — Safeguarding Protected Health Information (ePHI).
- **PCI-DSS v4.0** — Payment Card Industry Data Security Standard technical controls.
- **GDPR** — General Data Protection Regulation and data subject rights.

## Key Features

- **Certification Exam Simulation Engine**: Timed mock assessments with configurable question sizes (10, 25, 50 questions), realistic 75% passing thresholds, instant domain breakdowns, and automated XP rewards.
- **ComplianceVerse AI Assistant**: Interactive educational copilot powered by server-side Gemini 3.7 Flash for deep-dive control explanations, practical auditor dilemmas, and mistake debriefs.
- **Cross-Framework Mapping Matrix**: Side-by-side comparison engine correlating security controls across SOC 2, ISO 27001, NIST CSF, HIPAA, and PCI-DSS to eliminate audit redundancy.
- **Compliance Gap Analysis & Remediation**: Interactive control maturity evaluations with readiness scoring and automated 4-step remediation action roadmaps.
- **Gamified GRC Progression**: Level progression from Beginner Auditor to Lead Auditor, with study streaks, verifiable badges, and deterministic audit analytics.
- **Optional Supabase Cloud Sync**: Real-time persistent state synchronization with local fallback for complete privacy and instant zero-baseline readiness.
